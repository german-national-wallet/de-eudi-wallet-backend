# Contributing

This repository is a **one-way mirror**. Development happens in an internal repository, and snapshots are published
here for transparency.

## Issues

Issue tracking is enabled. Use [GitHub issues](https://github.com/german-national-wallet/de-eudi-wallet-backend/issues)
for bug reports, questions and suggestions about the published source. Please name the snapshot you looked at (the
commit, or the date in its subject).

Issues are triaged by the internal team. A fix arrives with a later snapshot; there is no commit here that references
the issue, so we close it once the snapshot that carries the fix is published.

**Do not report security vulnerabilities in issues.** Our bug bounty program is the channel for security findings, see
[SECURITY.md](SECURITY.md). An issue that describes a vulnerability may be removed, and you will be asked to submit it
through the program instead.

## Pull requests

Pull requests cannot be accepted. A pull request opened here cannot be merged: the branch is replaced wholesale by the
next published snapshot, so any change made here would be lost. To propose a change, open an issue describing it.

This may change. If contributions are opened up later, this document will say how.
